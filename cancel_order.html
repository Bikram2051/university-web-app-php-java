Cancel Order

Backend Handler — Not Available in Portfolio Demo

In the PHP version, this endpoint accepts a POST request from the manager dashboard, checks that the order's current status is PENDING (business rule: only pending orders may be cancelled), then executes a DELETE via prepared statement. Attempts to cancel non-pending orders are rejected with an error message stored in the session.
